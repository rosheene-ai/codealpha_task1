# task-1: Hangman Game

CodeAlpha Python Programming Internship - Task 1.

A text-based Hangman game where the player guesses a word one letter at a time.

## Features
- Random word from 5 predefined words
- 6 incorrect guesses allowed
- ASCII hangman drawing, input validation, play-again option

## Run
```
python hangman.py
```
Requires Python 3.8+ (no external libraries).

## Concepts Used
`random`, while loop, if-else, strings, lists
